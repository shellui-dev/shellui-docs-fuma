## What's New in v0.3.0

- **Compositional APIs**: Select, Dropdown, Popover, HoverCard, ContextMenu, NavigationMenu, Carousel, Tabs, Accordion, Collapsible, Drawer and Sheet all have subcomponent patterns, and `shellui add` installs the subcomponents with their parent
- **New components**: Callout, CopyButton, LinkCard, PrevNextNav, Sonner, Stepper
- **Also new**: [Command Palette](/docs/v0.3.0/components/advanced/command-palette), [Data Picker](/docs/v0.3.0/components/form/data-picker), [Multi Select](/docs/v0.3.0/components/form/multi-select), [Tag Input](/docs/v0.3.0/components/form/tag-input), [Typed Select](/docs/v0.3.0/components/form/typed-select), and the [Donut](/docs/v0.3.0/components/advanced/charts/donut-chart), [Radar](/docs/v0.3.0/components/advanced/charts/radar-chart) and [Radial](/docs/v0.3.0/components/advanced/charts/radial-chart) charts
- **Dependencies resolved for you**: `shellui add` installs sub-components, models, NuGet packages and `_Imports.razor` usings

## Getting Started

```bash
dotnet tool install -g ShellUI.CLI

# Add components
shellui add button input card drawer sheet

# The newest components
shellui add command-palette data-picker multi-select tag-input typed-select donut-chart radar-chart radial-chart
```
